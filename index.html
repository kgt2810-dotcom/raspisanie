Новое событие

Можно не заполнять: при сохранении сайт переведёт всё сам. Впиши свой вариант, только если автоперевод вышел неудачным.

Вложения: письма, файлы, фото

Фото сжимаются автоматически. Файлы до 20 МБ; большие лучше положить на Яндекс или Google Диск и прикрепить ссылкой.

Вход для старосты

Нужен ключ доступа от GitHub. Его создаёшь один раз на каждом своём устройстве (или один ключ на все):

  1. Открой github.com/settings/personal-access-tokens/new (нужно войти в GitHub).
  2. Token name: «Расписание». Expiration: самый долгий срок.
  3. Repository access: Only select repositories → выбери репозиторий сайта.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Нажми Generate token, скопируй ключ и вставь сюда.

Ключ хранится только в этом браузере и даёт доступ только к этому сайту. Никому его не пересылай.
